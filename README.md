# Анализ результатов онлайн-олимпиады для школьников

Учебный проект по аналитике данных (задание от VK).

> 🚧 Проект в работе. README будет дополняться по мере выполнения этапов.

## О проекте

EdTech-компания провела онлайн-олимпиаду для школьников из разных регионов.
Цель проекта — превратить "сырую" таблицу с результатами в понятную аналитику:
очистить данные, проверить их качество, найти закономерности и сформулировать
выводы о вовлечённости аудитории, сложности заданий и региональной специфике.

## Данные

- `olympiad_results.csv` — результаты 8 000 участников из 10 регионов
  (12 заданий на каждого): регион, школа, класс, время прохождения, ответы,
  итоговый балл, технические метрики сессии.
- `olympiad_data_dictionary.csv` — словарь данных.

В исходных данных есть пропуски, опечатки, дубликаты и аномальные сессии,
поэтому они требуют предобработки.

## Этапы работы

- [x] Разведочный анализ данных (EDA)
